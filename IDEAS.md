# RFC Garden — банк идей

> Креативная концепция развития: функционал, механики, контент, визуал.
> Монетизация исключена принципиально — только бесплатный продукт и сообщество.
> Статус: идеи, не ТЗ. Приоритет запуска — в конце документа.

## Блок 1. Новые механики взаимодействия

### 1. Режим «Прогулка садовника»
- **Что:** автопрокрутка камеры по саду с tap-to-pause; гид-подпись рассказывает про каждое растение, мимо которого плывём.
- **Как:** кнопка «Гулять» → камера идёт змейкой по ярусам, скорость ползунком, тап — пауза и карточка.
- **Визуал:** лёгкое покачивание камеры, глубина резкости (ближние чётко, дальние в дымке), светлячки сопровождают.
- **Польза:** нулевой порог входа — сад можно «смотреть как кино», решает проблему «не знаю, куда кликать».
- **Сложность:** средне.

### 2. Режим «Болезнь»
- **Что:** кнопка «Сломать» на карточке показывает, что умрёт вместе с протоколом.
- **Как:** выбираешь TCP → он сереет, гаснут все, кто от него зависит (HTTP, SSH, почта), счётчик «поражено: N».
- **Визуал:** увядание за 3 секунды — цвет уходит в серый, кристаллы осыпаются частицами вниз, связи рвутся с искрой.
- **Польза:** наглядно показывает вес каждого узла — главный вопрос «а зачем это учить».
- **Сложность:** средне.

### 3. Путешествие во времени
- **Что:** слайдер года 1958–2026; сад прорастает хронологически.
- **Как:** тянешь 1983 — в саду только TCP/IP, DNS, юный BGP; 2022 — влетает QUIC и HTTP/3 с эффектом посадки.
- **Визуал:** будущие растения — призрачные контуры, прошлое — зрелые кроны; год светится в небе сада.
- **Польза:** история сетей как единый нарратив, а не список дат.
- **Сложность:** средне.

### 4. Симуляция атаки
- **Что:** IDS-паразит (тёмный жук) ползёт по связям и грызёт выбранное растение.
- **Как:** кнопка «Атаковать» → выбираешь тип (DDoS/фишинг/MITM) → смотришь, где рвётся; кнопка «Залатать» чинит через TLS/файрвол.
- **Визуал:** чёрно-красный сгусток с искрами ползёт по ребру, укушенное место чернеет, латка — золотая заплатка-плёнка.
- **Польза:** безопасность перестаёт быть абстракцией; связка «атака → защита» в одном кадре.
- **Сложность:** высоко.

### 5. Конструктор сети
- **Что:** песочница «собери цепочку»: перетаскиваешь растения в грядку (например, DNS → TCP → TLS → HTTP) и жмёшь «Запустить пакет».
- **Как:** светящаяся бусина-пакета бежит по собранной цепочке; разорванная цепь — пакет падает в землю с объяснением, чего не хватает.
- **Визуал:** грядка-планшет внизу экрана, пакет оставляет светящийся след, финиш — цветок «страница открылась».
- **Польза:** стек протоколов собирается руками — понимание через действие, а не чтение.
- **Сложность:** высоко.

### 6. Выращивание своего протокола
- **Что:** конструктор «придумай RFC»: имя, год, от чего зависит, кого кормит → в саду вырастает твоё растение.
- **Как:** 4 шага формы → генерация по тем же L-системам (сид из названия) → растение садится в сад с бейджем «выращено тобой», хранится в localStorage.
- **Визуал:** ускоренная анимация прорастания 5 секунд — росток пробивает почву, раскрывается, получает твой цвет.
- **Польза:** авторство = strongest retention; студенты помнят то, что «посадили».
- **Сложность:** средне.

### 7. Пакет-путешественник
- **Что:** режим от первого лица пакета: выбираешь сайт (например, «открыть почту») — и летишь по всей цепочке протоколов.
- **Как:** камера следует за светящейся бусиной DNS → TCP → TLS → IMAP, на каждой остановке всплывает одна строка «что здесь произошло».
- **Визуал:** motion-blur след, лёгкий зум на узлах.
- **Польза:** отвечает на вечный вопрос «а что происходит, когда я жму кнопку».
- **Сложность:** средне.

### 8. Погода сада
- **Что:** глобальные события — «DDoS-гроза», «тихая ночь», «утренний туман обновлений».
- **Как:** гроза случайно (или по кнопке) накрывает сад: молнии бьют в хабы, трафик-частицы ускоряются; туман приглушает устаревшие протоколы.
- **Визуал:** тучи-градиенты сверху, молнии-ломаные с flash-кадром, туман — низкий белый шум по земле.
- **Польза:** сад живой даже без кликов; погода — метафора сетевых состояний (конгестия, простой, maintenance-окно).
- **Сложность:** средне.

### 9. Опыление (кросс-зависимости)
- **Что:** выбери два растения — сад покажет их общего потомка и полный путь родства.
- **Как:** клик по двум узлам → подсвечивается кратчайший путь между ними через предков, плюс карточка «что их связывает».
- **Визуал:** путь цветёт — по рёбрам распускаются мелкие цветы, остальные гаснут.
- **Польза:** граф зависимостей читается как родословная, а не паутина.
- **Сложность:** низко.

### 10. Квесты садовника
- **Что:** цепочки заданий от персонажа («Найди растение, которое держит всю почту», «Вылечи три больных узла»).
- **Как:** 3–5 шагов с подсказками-«приметами», прогресс-лейка наполняется; награда — редкий облик растения.
- **Визуал:** садовник-светлячок ведёт камеру к цели, цель пульсирует золотым кольцом.
- **Польза:** превращает бесцельное блуждание в игру с целью.
- **Сложность:** средне.

### 11. Сезоны нагрузки
- **Что:** переключатель «утро/пик/ночь» меняет сад: днём трафик-частицы густые, ночью сад спит (тускло, светлячки).
- **Как:** один тоггл в тулбаре; ночной режим заодно экономит батарею.
- **Визуал:** палитра неба и плотность частиц перетекают за 2 секунды.
- **Польза:** интуиция про суточные паттерны трафика + атмосферная фишка для возвратов.
- **Сложность:** низко.

## Блок 2. Новые образовательные механики

### 1. «Поставь диагноз»
- **Что:** сад показывает увядшее растение с симптомами («сайты не открываются, ping идёт»), ты выбираешь больной протокол из четырёх.
- **Как:** 5 случайных кейсов за раунд; ошибка — сад показывает цепочку поломки целиком.
- **Мотивация:** роль врача, а не ученика; разбор реальных инцидентов вместо зубрёжки.
- **Метафора:** больница сада / карантинная грядка.
- **Сложность:** низко.

### 2. «Собери растение»
- **Что:** протокол разобран на части (корень-транспорт, стебель-сессия, цветок-приложение) — собери HTTP из TCP+TLS+методов.
- **Как:** drag-and-drop трёх ярусов; неверная сборка не приживается (часть отваливается с подсказкой).
- **Мотивация:** конструктор + тактильность; нельзя угадать — надо понять.
- **Метафора:** прививка черенков в садоводстве.
- **Сложность:** средне.

### 3. Гербарий достижений
- **Что:** коллекция открытых растений в виде гербарных листов; открыл 10 — «Редкий папоротник», все транспортные — «Хранитель потоков».
- **Как:** localStorage-прогресс, 20+ ачивок с условиями (открыть, вылечить, собрать, пройти время), страница-альбом.
- **Мотивация:** коллекционирование — самая липкая механика; хочется «дособрать».
- **Метафора:** гербарий 1-в-1, вплоть до бумажной текстуры карточек.
- **Сложность:** низко.

### 4. Тропы садовника (мини-курсы)
- **Что:** 3 готовые тропы: «Выживи в сетях за неделю», «Почта от и до», «Безопасность с нуля» — узлы ordered-маршрутом с чекпоинтами.
- **Как:** тропа подсвечивает следующий узел, прогресс-бар, в конце — именной «сертификат садовника» (PNG на память, бесплатно).
- **Мотивация:** конечная видимая цель + сертификат для портфолио.
- **Метафора:** садовые дорожки с указателями и скамейками-чекпоинтами.
- **Сложность:** средне.

### 5. Флеш-карточки «лист/оборот»
- **Что:** карточка-растение: видишь силуэт — называешь протокол; клик — переворот с фактами.
- **Как:** режим «вечерний повтор» — 10 карт, алгоритм показывает чаще те, где ошибся (мини-SM2).
- **Мотивация:** 5 минут в день, умные повторы вместо зубрёжки.
- **Метафора:** гербарные карточки, которые надо «опознать по листу».
- **Сложность:** низко.

### 6. Паутина глоссария
- **Что:** глоссарий не списком, а мини-садом терминов: клик по термину раскрывает его связи-паутинки с соседями.
- **Как:** поиск + граф 2-го уровня от термина; каждый термин — семечко с one-line определением.
- **Мотивация:** определения запоминаются через соседей, а не в вакууме.
- **Метафора:** корневая система под садом — термины и есть корни.
- **Сложность:** средне.

### 7. «Слепой сад»
- **Что:** все подписи скрыты, растения — только силуэты; опознай 10 по форме (гриб-хаб? цветок-почта?).
- **Как:** раунд на время, за ошибку силуэт «шепчет» подсказку (год или факт).
- **Мотивация:** азарт узнавания + тренировка визуальной памяти, которой нет ни в одном учебнике.
- **Метафора:** ночной сад, где растения узнают на ощупь.
- **Сложность:** низко.

### 8. Парочки (мемори)
- **Что:** memory-match: 8 пар «растение ↔ RFC-номер», карточки лежат рубашкой вверх на грядке.
- **Как:** открыл две — совпали (вспышка опыления) или нет; счёт ходов, рекорд в localStorage.
- **Мотивация:** классическая залипательная механика + номера RFC влетают сами собой.
- **Метафора:** клумба с перевёрнутыми горшками.
- **Сложность:** низко.

### 9. Растение дня
- **Что:** каждый день одно растение подсвечено золотом + один вопрос про него; серия ответов подряд = streak.
- **Как:** streak и календарь посещений в localStorage, пропуск обнуляет.
- **Мотивация:** streak — сильнейший крючок возврата; один факт в день не утомляет.
- **Метафора:** «цветок дня» в витрине оранжереи.
- **Сложность:** низко.

### 10. Печатный гербарий
- **Что:** кнопка «Распечатать набор» — чёрно-белая колода карточек (растение-контур, имя, 3 факта) для пары без проектора.
- **Как:** print-CSS (no-print классы уже есть) + раскладка 3×3 и кнопка.
- **Мотивация:** мост в офлайн-аудиторию; преподаватели — канал дистрибуции.
- **Метафора:** настоящий гербарий, который можно потрогать.
- **Сложность:** низко.

## Блок 3. Наполнение информацией

Формат: **Название — ярус · растение · факты · визуал**.

### Протоколы
1. **OSPF** — network · дерево с переплетающимися корнями · link-state, алгоритм Дейкстры, зоны/area 0 · корни-карта топологии вокруг.
2. **WireGuard** — network · кактус (мало кода — мало иголок, но острые) · ~4000 строк кода, ChaCha20, roaming · тоннель-труба между двумя кактусами.
3. **MQTT** — application · подсолнух (головка-брокер, лепестки-подписчики) · pub/sub, топики, QoS 0/1/2 · пчёлы-пакеты летят к головке.
4. **DNSSEC** — application · цветок в стеклянном колпаке · цепочка доверия, DS-записи, валидация · колпак трескается, если подпись битая.
5. **mDNS/Bonjour** — link · куст без садовника (zero-conf) · .local, multicast, принтеры и Apple TV · куст сам разрастается без грядки.
6. **SCTP** — transport · бамбук-роща (стримы-стебли из одного корня) · мультистриминг, multihoming, SIGTRAN/4G · 4 стебля из одного корня.

### Оборудование
1. **Хаб (концентратор)** — link · сухой пень (музейный экспонат) · повторяет всё всем, коллизии, умер к 2000-м · пень с табличкой «вымер».
2. **IDS-сенсор** — network · росянка (хищное растение) · SPAN-порт, сигнатуры, passive-режим · капли-росы ловят мушек-пакетов.
3. **WAF** — application · живая изгородь перед клумбой веба · OWASP Top-10, сигнатуры+ML, false positive · изгородь сдвигается при атаке.
4. **Оптоволоконный кабель** — physical · ручей через весь сад · свет вместо тока, single/multi-mode, затухание в дБ · по ручью плывут светящиеся лодочки-биты.
5. **NAS-хранилище** — application · дуб с дуплом-складом · NFS/SMB, RAID, снапшоты · жёлуди-файлы с версиями.
6. **Обратный прокси** — application · привратник-гриб у входа в клумбу · termination TLS, кэширование, балансировка · грибы-очередь проходят через арку.

### Операционные системы
1. **FreeBSD** — network · красный клён · jails (предок контейнеров), ZFS, Netflix отдаёт с него видео · мини-клетки-jails на ветвях.
2. **MS-DOS** — network · окаменелость в почве · 640K barrier, COMMAND.COM · слой-окаменелость под Windows-деревом.
3. **ChromeOS** — network · вьюнок на заборе · всё в браузере, verified boot, Crostini · вьюнок тянется только к облаку-опоре.
4. **FreeRTOS** — physical · мох на камнях IoT · килобайты RAM, тики планировщика, датчики · мох покрывает камешки-датчики.
5. **Plan 9** — network · теплица-эксперимент · «всё — файл» до предела, UTF-8 отсюда, наследие в Go · горшки с бирками-принципами.
6. **OpenBSD** — network · черепаха-кактус · OpenSSH отсюда, аудит кода, pufferfish · рыба-шар среди колючек.

### Виртуализация
1. **QEMU** — application · хамелеон (эмулирует любое железо) · TCG, KVM-ускорение, системная и user-мода · меняет окраску под гостя.
2. **Proxmox** — application · оранжерея со стеллажами · KVM+LXC из одной панели, кластер, бэкапы · стеллажи с горшками-VM и ящиками-контейнерами.
3. **Podman** — application · гриб-одиночка (без демона) · daemonless, rootless, замена Docker CLI · гриб без общей грибницы.
4. **Terraform** — application · садовый план-чертёж · declarative, state-файл, провайдеры · полупрозрачный чертёж поверх грядки, `apply` высаживает.
5. **Firecracker** — application · ростки в наперстках (microVM) · старт 125ms, serverless, изоляция · сотни наперстков-грядок.
6. **Xen** — application · старое дерево с дуплом · паравиртуализация, dom0/domU, AWS начинался на нём · дупло с этажами-доменами.

### Программирование
1. **Java** — application · кофейное дерево · JVM «write once», GC, Spring/enterprise · зёрна-байткод мелятся в жерновах JVM.
2. **TypeScript** — application · прививка на JavaScript-дереве · типы поверх JS, tsc, DefinitelyTyped · бирки-типы на каждой ветке JS.
3. **SQL** — application · колодец с вёдрами-запросами · SELECT/JOIN, транзакции ACID, индексы · ведро JOIN достаёт воду из двух колодцев сразу.
4. **Bash** — application · лопата садовника · пайпы `|`, скрипты, cron · лопата копает траншеи-пайплайны между грядками.
5. **Erlang** — application · муравейник (акторы) · actor model, hot code reload, 9 девяток uptime АТС · муравьи-письма не делят память.
6. **Ассемблер** — physical · корни под почвой · MOV/регистры, один-к-одному с машинным кодом · корни с бирками опкодов, видно в «рентген-режиме» почвы.

### Искусственный интеллект
1. **Перцептрон (1958)** — application · первое семечко ИИ · Розенблатт, веса, критика Минского · семечко с одним корешком-весом.
2. **Экспертные системы** — application · картотека-куст · база правил IF-THEN, MYCIN, зима ИИ · зимой сбрасывает листья-правила.
3. **CNN** — application · глаз-цветок (слои-лепестки) · свёртки, LeNet/ImageNet · лепестки-фильтры скользят по картинке-пчеле.
4. **LSTM** — application · слон-растение с памятью · gates (forget/input), последовательности · хобот-конвейер помнит очередь слов.
5. **GAN** — application · два борющихся вьюнка (генератор vs дискриминатор) · minimax-игра, mode collapse, deepfake · вьюнки душат друг друга по очереди.
6. **Диффузия** — application · туман, из которого проступает цветок · шум→картинка, Stable Diffusion, steps · ползунок шагов развеивает туман в детали.

### История IT
1. **ARPANET 1969** — network · первое посаженное дерево · 4 узла, NCP, Клейнрок · табличка «здесь всё началось», лунка с годом.
2. **Email @ 1971** — application · почтовый ящик-скворечник · Томлинсон, выбор @ · птицы-письма влетают в скворечник.
3. **Ethernet 1973** — link · паутина Меткалфа · CSMA/CD, закон Меткалфа, Xerox PARC · паутина растёт с каждым узлом.
4. **Червь Морриса 1988** — application · первая тля-вредитель · 6000 машин, finger/sendmail, первый приговор по CFAA · тля-пиксель ползёт по стеблям.
5. **Mosaic 1993** — application · витрина оранжереи · первый массовый браузер, картинки в тексте · стеклянная витрина, толпа-муравьи у входа.
6. **Heartbleed 2014** — presentation · треснувшее стеклянное сердце · OpenSSL, heartbeat-extension, смена ключей всего интернета · из трещины капают байты-память.

### Безопасность
1. **RSA/AES** — presentation · замок-амбар с двумя ключами · открытые/закрытые ключи, Диффи-Хеллман, 1977 · два разных ключа открывают один амбар.
2. **TOTP/2FA** — session · часы с меняющимися цветами · 30-секундное окно, shared secret, RFC 6238 · лепестки-цифры опадают каждые 30 секунд.
3. **Passkeys** — session · отпечаток на лепестке · WebAuthn, без паролей, phishing-resistant · цветок узнаёт садовника «в лицо».
4. **Honeypot** — network · цветок-ловушка с нектаром · заманивает сканеры, логи атак · мухи-сканеры липнут, садовник изучает.
5. **Энигма** — presentation · шифр-камень с роторами · роторы, Блетчли-парк, Тьюринг · покрути роторы-камни — надпись меняется.
6. **Tor** — application · луковица (слои!) · onion routing, 3 реле, мосты · снимаешь слой за слоем, в сердцевине — адрес .onion.

### Облачные технологии
1. **S3-хранилище** — application · бесконечный колодец · бакеты, 11 девяток durability, версии · бросил ведро — достал любую версию.
2. **CDN** — application · одуванчик · edge-PoP, кэширование, anycast · дунул — семена-копии разлетелись по краям сада.
3. **Serverless** — application · грибы-дождевики · pay-per-use, cold start, stateless · гриб вспыхивает на запрос и тает.
4. **VPC** — network · огороженный участок с калиткой · подсети, security groups, peering · забор, калитка с ACL-списком.
5. **SaaS** — application · яблоня самообслуживания · подписка, multitenancy, SLA · срываешь яблоко — оно уже помыто (managed).

### Сети
1. **LAN** — link · домашняя клумба за забором · Ethernet/Wi-Fi, broadcast-домен, 192.168 · уютная огороженная клумба.
2. **WAN** — network · караванный путь через пустырь · провайдеры, MPLS, задержки · верблюды-пакеты идут медленно, но далеко.
3. **Mesh** — network · грибница (единый организм) · ретрансляция, самовосстановление · под землёй светящаяся сеть нитей.
4. **VLAN** — link · цветные ленточки на одном кусте · 802.1Q теги, trunk/access · один куст, ленты не смешиваются.
5. **IXP (точка обмена)** — network · базар-перекрёсток · пиринг, route servers, AMS-IX/MSK-IX · торговцы-сети меняются пакетами из рук в руки.
6. **Subnetting/CIDR** — network · разметка грядок колышками · маска, /24, VLSM · колышки делят грядку на делянки.

### Стандарты и организации
1. **IETF** — вне ярусов · вече у костра · RFC-процесс, «грубый консенсус и рабочий код» · табуретки по кругу, черновики-уголёки.
2. **ICANN/IANA** — network · раздаточная корней · пулы IP, корневая зона DNS, RIR · садовник раздаёт номерные горшки.
3. **W3C** — application · палисадник веба · HTML/CSS-стандарты, validator · эталонные грядки «как должно расти».
4. **IEEE 802** — link/physical · чертёжная мастерская · Ethernet/Wi-Fi-стандарты, рабочие группы · циркули и линейки поверх кустов.
5. **RIPE NCC** — network · региональный питомник · распределение в Европе, LIR, IPv4-runout · табличка «саженцы IPv4 закончились».

### Концепции
1. **Модель OSI** — вне ярусов · террасный склон из 7 ступеней · 7 уровней, инкапсуляция · камера поднимается по террасам, пакет обрастает конвертами.
2. **Клиент-сервер** — application · колодец и жаждущие ростки · запрос-ответ, API · очередь ростков с вёдрами к колодцу.
3. **P2P** — application · хоровод одинаковых цветов · без центра, DHT, торренты · цветы передают мяч-пакет по кругу, ведущего нет.
4. **End-to-end принцип** — network · «умные края, глупая середина» · Saltzer/Reed/Clark 1981 · середина — простая тропинка, всё умное по краям.
5. **Zero Trust** — session · теплица с проверкой у каждой грядки · «никому не верь», микросегментация · пропуск спрашивают даже у своих пчёл.

## Блок 4. Новые визуальные элементы

### 1. Грибница (мицелий) для mesh/P2P
- **Что:** светящаяся сеть нитей под почвой, соединяющая родственные растения.
- **Как выглядит:** в обычном виде — faint-точки на земле; в «рентген-режиме» почвы — яркая паутина.
- **Где:** включается для mesh/P2P/Tor-растений и в режиме «корни» глоссария.
- **Польза:** децентрализация видна буквально под ногами.
- **Сложность:** средне.

### 2. Ручей TCP
- **Что:** извилистый светящийся ручей, текущий сверху вниз через все ярусы.
- **Как выглядит:** поток частиц с течением, мостики-шлюзы (NAT) через него, лодочки-пакеты.
- **Где:** фоновая ось сада, всегда; пакеты конструктора плывут по нему.
- **Польза:** единая «река данных» собирает сад в цельную сцену вместо россыпи точек.
- **Сложность:** средне.

### 3. Камни-фундаменты
- **Что:** 5–7 гранитных валунов с высеченными RFC-номерами столпов (791, 793, 1035, 2616, 8200).
- **Как выглядит:** мох, трещины, таблички; клик — прыжок к растению-протоколу.
- **Где:** вдоль главной тропы от входа.
- **Польза:** якоря навигации + мгновенное чтение «что тут главное».
- **Сложность:** низко.

### 4. Теплица-песочница
- **Что:** стеклянный купол, внутри — копии растений для опытов (болезни, атаки без вреда саду).
- **Как выглядит:** купол с бликом, внутри мини-грядка; всё, что ломается внутри, остаётся внутри.
- **Где:** отдельный угол сада; туда же переезжают «Болезнь» и «Атака» как безопасные режимы.
- **Польза:** свобода экспериментировать без страха «сломать сад».
- **Сложность:** средне.

### 5. Туман неактивного
- **Что:** устаревшие (legacy) растения стоят в лёгком тумане и серебристой дымке.
- **Как выглядит:** низкий alpha-шум + desaturate; при наведении туман расходится кольцом.
- **Где:** всегда, для status=legacy.
- **Польза:** статус читается без бейджей — atmosphere as UI.
- **Сложность:** низко.

### 6. Рой пакетов NetPulse
- **Что:** живые пакеты из локального NetPulse-демо летают по саду как светлячки.
- **Как выглядит:** рой из 20–50 мошек с trails; плотность = реальный pps с твоей машины.
- **Где:** поверх сада, тоггл «живой трафик».
- **Польза:** мост «мой компьютер ↔ этот сад» — магия персонализации.
- **Сложность:** средне.

### 7. Кольца версий на стволах
- **Что:** у стволов деревьев — годичные кольца = мажорные версии протокола.
- **Как выглядит:** при зуме на стволе проступают кольца с подписями (TLS 1.0/1.1/1.2/1.3).
- **Где:** крупные деревья (TCP, TLS, HTTP, IP).
- **Польза:** эволюция стандарта видна на «срезе», а не в Википедии.
- **Сложность:** средне.

### 8. Плоды-счётчики
- **Что:** на орбах-плодах выгравировано число (зависимости, RFC-номер, год).
- **Как выглядит:** цифра светится внутри стеклянной сферы, читается при зуме.
- **Где:** все плодоносящие узлы.
- **Польза:** цифры запоминаются через образ, а не таблицу.
- **Сложность:** низко.

### 9. Молнии DDoS и радуга восстановления
- **Что:** событийные анимации — атака (ломаные разряды + flash) и исцеление (дуга-радуга над выздоравливающим).
- **Как выглядит:** молния — 5 сегментов + screen flash 120мс; радуга — 3 дуги, тающие за 4с.
- **Где:** режимы атаки/болезни/лабораторий.
- **Польза:** эмоциональные пики — то, ради чего возвращаются.
- **Сложность:** средне.

### 10. Террасы ярусов OSI
- **Что:** ярусы сада — физические террасы-ступени с подписями уровней на торцах.
- **Как выглядит:** 7 каменных ступеней, ручей TCP стекает каскадом, растения стоят на своих ступенях.
- **Где:** компоновка сада (эволюция positionProtocols).
- **Польза:** модель OSI перестаёт быть схемой — по ней буквально ходят.
- **Сложность:** высоко.

## Блок 5. Новые форматы контента

### 1. Аудио-гид «Сад вслух»
- **Что:** озвучка карточек и прогулок через Web Speech API — ноль инфраструктуры, работает голосами ОС.
- **Зачем:** доступность для незрячих + «слушать сад» в дороге.
- **Вписывается:** садовник-рассказчик уже есть как персонаж квестов.
- **Сложность:** низко.

### 2. Терминал-песочница
- **Что:** встроенный fake-terminal: ping, traceroute, dig, curl — с анимированным «выводом», привязанным к саду (traceroute подсвечивает узлы!).
- **Зачем:** студенты учат команды без Linux под рукой; связка «команда → картинка».
- **Вписывается:** теплица-песочница как дом для терминала.
- **Сложность:** средне.

### 3. Видео-тропы
- **Что:** режим автопрогулки + запись canvas в webm одной кнопкой («Сохранить тур») для учебных видео.
- **Зачем:** преподаватели получают готовые ролики, студенты — материал для докладов.
- **Вписывается:** прогулка + MediaRecorder, всё клиентское.
- **Сложность:** низко.

### 4. Народный гербарий (краудсорс растений)
- **Что:** форма «Предложи растение»: тема, факты, цвет → модерация → новый росток в саду с авторством.
- **Зачем:** контент масштабируется сообществом; авторы приводят друзей.
- **Вписывается:** механика «выращивания» + теплица как карантин для новичков.
- **Сложность:** средне (форма + очередь в GitHub Issues).

### 5. Открытый API и embed-виджеты (100% бесплатно)
- **Что:** `protocols/tcp.json` + iframe-виджет «растение недели» для чужих сайтов и GitHub README. Без лимитов и платных тиров — чисто для распространения знаний.
- **Зачем:** сад расползается по интернету (обратные ссылки, узнаваемость), сторонние курсы встраивают.
- **Вписывается:** данные уже структурированы (data.js ≈ готовое API), exportPng уже умеет картинки.
- **Сложность:** средне (минимальный хостинг JSON).

### 6. Тропы-статьи с ветвлением
- **Что:** choose-your-own-adventure разборы инцидентов («Упала почта. Твои действия?» — 3 развилки, 2 концовки).
- **Зачем:** нарратив держит лучше тестов; преподавателям готовые кейсы для пар.
- **Вписывается:** статьи живут в саду как «беседки» — точки отдыха с историей.
- **Сложность:** средне.

## Дополнительно (вне блоков)

### А. Виджет «Моё растение» для GitHub README
- Бейдж-картинка: любимое растение + streak гербария. Обновляется ссылкой с параметрами (чистый SVG, без бэкенда — генерация через data-URL, exportPng уже умеет).
- Польза: бесплатная реклама в тысячах профилей.
- Сложность: низко.

### Б. Скринсейвер «Ночной сад»
- Отдельная лёгкая страница: только сад, медленная камера, часы. Для второго монитора и проекторов на кафедрах.
- Польза: ambient-присутствие бренда + wow на открытых днях.
- Сложность: низко (готовая сцена + автокамера прогулки).

### В. Семена (реферальная механика без спама)
- Персональная ссылка «посади друга»: друг открывает — у обоих прорастает парный цветок-мост.
- Польза: виральность через заботу, а не спам.
- Сложность: средне.

## Рекомендуемый порядок запуска

1. **Гербарий достижений + Растение дня** — неделя работы, дают retention.
2. **Болезнь + Прогулка** — виральность и глубина.
3. **Конструктор + Тропы садовника** — флагманы.
4. Параллельно: **Аудио-гид** (дешёвая доступность) и **Народный гербарий** (контент-машина).
5. Второй эшелон: всё остальное из блоков 4–5.
