Что внутри

Сад — это карта. Каждое растение рассказывает историю стандарта.

Живые растения

Деревья, лианы, цветы и грибы — четыре формы для разных ролей протоколов. Размер = количество связей.

Граф зависимостей

Пунктирные линии показывают, что на чём построено: HTTP растёт из TCP, TCP — из IP.

Частицы данных

Светящиеся точки бегут по связям, показывая путь пакета через стек протоколов.

Карточки знаний

Клик по растению — год принятия, статус, описание человеческим языком и ссылка на оригинал документа.

Уровни сада

Протоколы организованы по слоям сетевого стека. Кликните — сад откроется на этом слое.

Application
HTTP · DNS · SMTP · SSH — то, что видят приложения
Presentation
TLS · PBKDF2 — шифрование и безопасность
Session
SIP · SDP · OAuth — установка и жизнь сессий
Transport
TCP · UDP · QUIC — доставка данных
Network
IPv4 · IPv6 · ICMP — адресация и маршрутизация
Link
ARP · Switch — кадры и MAC-адреса локалки
Physical
Modem · Wi-Fi — провода, воздух и гудки

О проекте

RFC Garden — open-source визуализация мира сетевых стандартов: сухие технические документы превращены в живую экосистему. Для студентов, сетевых инженеров и всех, кто хочет понять, как устроен интернет.
