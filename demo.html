На проводе

Повтори сам и обнови живой сайт

1. Прогони наблюдение на стороне labspin — Proxmox для демо-конфига не нужен:

python main.py observe -c config.yaml --json-out netpulse_evidence.json

2. Положи свежий файл в корень сайта:

copy netpulse_evidence.json C:\rfc-garden\

3. Закоммить и запушь — живой сайт подхватит цифры сам:

git -C C:\rfc-garden add netpulse_evidence.json && git -C C:\rfc-garden commit -m "demo: fresh evidence" && git -C C:\rfc-garden push

Данные выше — реальный прогон на localhost. Страница показывает встроенный пример, а затем пытается загрузить netpulse_evidence.json рядом с собой.
