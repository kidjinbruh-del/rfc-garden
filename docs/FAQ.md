# FAQ / Частые вопросы

## RU
- **Это требует сервер?** Нет. Статика, работает через `file://`.
- **Как открыть конкретный протокол?** `explore.html#rfc0793` (deep-link).
- **Тормозит. Что делать?** `?perf=low` (или med/high) + ночной режим экономит батарею.
- **Как добавить протокол?** См. [CONTRIBUTING.md](../CONTRIBUTING.md): `PROTOCOLS.json` + `js/data.js` + паспорт.
- **Где тесты?** `node tests/run-all.js` (только Node.js).
- **Можно ли использовать в учёбе?** Да, MIT. Шпаргалка печатается, лабы — для преподавателей.

## EN
- **Server needed?** No. Static files, works via `file://`.
- **Open a specific protocol?** `explore.html#rfc0793` (deep-link).
- **Slow?** Try `?perf=low`.
- **Add a protocol?** See [CONTRIBUTING.md](../CONTRIBUTING.md).
- **Tests?** `node tests/run-all.js` (Node.js only).
- **Classroom use?** Yes, MIT. Printable cheatsheet, teacher labs included.
