Посадить свой протокол

Сад растёт из данных. Один JSON-объект — новое растение.

1Выберите RFC

Найдите протокол на rfc-editor.org, которого ещё нет в саду.

2Опишите растение

Добавьте объект в конец массива protocols в PROTOCOLS.json и js/data.js:

{ "id": "rfc9001", "number": 9001, "name": "TLS 1.3", "fullName": "Transport Layer Security", "year": 2018, "status": "active", // active | updated | legacy "layer": "presentation", // application | transport | network "category": "security", "plant": "tree", // tree | vine | flower | mushroom | sprout "description": "Шифрование соединений человеческим языком.", "dependsOn": ["rfc0793"], // id протоколов-оснований "usedBy": [], "replaces": [], // какие RFC заменяет "replacedBy": [], // чем сам заменён "color": "#4DD0E1" }

3Отправьте PR

Fork → ветка → коммит → Pull Request в репозиторий проекта. Сад пересчитает размеры и связи автоматически.

Правила посадки

Описание — человеческим языком, без канцелярита. Цвет — контрастный к уже занятым. dependsOn — только существующие id. Один PR — один протокол.
